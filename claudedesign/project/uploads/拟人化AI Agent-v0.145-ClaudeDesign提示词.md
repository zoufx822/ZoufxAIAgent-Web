# v0.145 StatePanel「记忆锚点」区域样式改动

## 项目背景

拟人化 AI Agent，前端 Next.js + Tailwind CSS v4，右侧 280px 状态面板（StatePanel）展示 AI 对用户的认知和记忆状态。

## 改动范围

StatePanel 第四个 section：**「记忆片段」→「记忆锚点」**

仅改此 section 的标题和内容，其余三个 section（用户印象 / 当前状态 / 近期工具调用）不动。

## 改动前（当前线上样式）

```
┌─ 记忆片段 ───────────── 5 ─┐
│ ┌─────────────────────────┐│
│ │ user · 2026-05-25       ││
│ │ 帮我搜索北京今天的天气    ││
│ └─────────────────────────┘│
│ ┌─────────────────────────┐│
```

## 改动后（目标样式）

展示的是 LLM 在当前对话上下文中的**跨锚点压缩摘要**——即 AI 知道之前聊过什么。内容来自 `AnchorContextSection` 生成的分层摘要，UI 按衰减层级分组展示。

```
┌─ 记忆锚点 ──────────────────┐
│                              │
│  近记忆（最近对话）            │
│  ┌─────────────────────────┐ │
│  │ React 学习              │ │
│  │ 对方在学 hooks，问了     │ │
│  │ useState/useEffect 区别… │ │
│  └─────────────────────────┘ │
│  ┌─────────────────────────┐ │
│  │ 周末计划                │ │
│  │ 对方计划爬山，问了装备…  │ │
│  └─────────────────────────┘ │
│                              │
│  中记忆（较早对话）            │
│  ┌─────────────────────────┐ │
│  │ TypeScript 泛型 · 摄影   │ │
│  └─────────────────────────┘ │
│                              │
│  远记忆                      │
│  ┌─────────────────────────┐ │
│  │ 3 个更早的对话            │ │
│  └─────────────────────────┘ │
└──────────────────────────────┘
```

## 设计要点

### 1. 三层视觉区分

| 层级 | 摘要长度 | 视觉权重 | 建议样式 |
|------|---------|---------|---------|
| 近记忆 | ~200 字/条 | 重 | 卡片 + 标题 + 正文，最大视觉比重 |
| 中记忆 | ~50 字/条 | 中 | 紧凑卡片，单行标题 + 一行内容 |
| 远记忆 | 一行标题 | 轻 | 折叠或最小化展示，仅显示"几个对话"的概要 |

### 2. 层级折叠

- 近记忆默认展开
- 中记忆默认半折叠（只显示标题行）
- 远记忆默认全折叠（只显示一行"共 N 个对话的摘要"）

### 3. 时间锚

每条摘要需带时间标签（如"3 天前"、"上周"、"2024 年"），让用户知道这条记忆的时间远近。

### 4. 情绪关联（可选）

如果对话当时的 mood 有记录，可以附一个情绪标记（如平静 / 兴奋），增加拟人感。

### 5. 空状态

无其他锚点时，显示"这是我们的第一次对话"或类似拟人化文案。

## 技术约束

- 宽度固定 280px，内容需适配
- 使用内联 style 对象（项目已有模式），配合 Tailwind class 工具类
- 中文 UI
- 深色/浅色主题通过 CSS 变量切换（`var(--bg)`、`var(--border)`、`var(--t1)`、`var(--t2)`、`var(--t3)`、`var(--surface)`）

## 项目视觉风格参考

- 拟人化、温和克制、不卖萌
- mono 字体用于标签/层级标题（`letterSpacing: '0.14em'`、`textTransform: 'uppercase'`）
- 小字号正文（11-12px）
- 卡片圆角 8px、`border: 1px solid var(--border)`、`background: var(--surface)`
- 色阶：`var(--t1)` 主文字、`var(--t2)` 次要、`var(--t3)` 辅助/标签
