# 小Z 眼睛系统改动提示词
## 前端实现说明 · v0.15 rev2

以下变更均已在设计原型中验证，请按此实现。不包含嘴巴元素（后续迭代）。

## 1. 愉快情绪 — 全新表情设计

### 问题背景
旧实现使用自定义 `clipPath`（底部曲线挖空）+ 瞳孔 cy 上移至 17.3，导致「半截眼 + 瞳孔顶上去」的猥琐感，需完全替换。

### 新 MOOD_EXPR 参数
```js
'愉快': { pr: 3.9, pdy: 0, esy: 1.00, blink: 4.0, liddy: 0, lidty: 0 }
```
圆眼完全不变（无 clipPath 修改，无 esy 压缩），表情通过瞳孔形变和外部符号表达。

### 新眼睛渲染（happyFace 分支替换）
条件：`mood === '愉快' && !asleep && !waking && !thinking && !drifting`

```jsx
// 隐藏常规眼睛（保持原有 happyFace 遮蔽逻辑）
// 渲染新 happy-face 组：
<g className="happy-face">
  {/* 实心红点腮红 */}
  <circle className="happy-dot"   cx="11" cy="37" r="2.9" fill="#f06070"/>
  <circle className="happy-dot r" cx="89" cy="37" r="2.9" fill="#f06070"/>

  {/* 左眼：圆眼 + 新月形瞳孔 */}
  <g className="eye eye-l" clipPath={`url(#${maskL})`}>
    <ellipse cx="28" cy="22" rx="13" ry={ryL} fill={fill}/>
    <g className="pupil happy-pupil pupil-l">
      <circle cx="28" cy="22"   r="3.9"  fill={pp}/>    {/* 白色底圆 */}
      <circle cx="28" cy="25.1" r="3.55" fill={fill}/>  {/* 深色覆盖圆，下移 3.1，形成上弦月 */}
    </g>
  </g>

  {/* 右眼：同左眼 */}
  <g className="eye eye-r" clipPath={`url(#${maskR})`}>
    <ellipse cx="72" cy="22" rx="13" ry={ryR} fill={fill}/>
    <g className="pupil happy-pupil pupil-r">
      <circle cx="72" cy="22"   r="3.9"  fill={pp}/>
      <circle cx="72" cy="25.1" r="3.55" fill={fill}/>
    </g>
  </g>
</g>
```

### 新 CSS 动画
```css
/* 愉快瞳孔漂移 —— 已有 happy-bob，pupil-r 加 delay */
.eyes-z.happy .happy-pupil { animation: happy-bob 9s ease-in-out infinite; }
.eyes-z.happy .pupil-r     { animation-delay: .12s; }

/* 腮红红点律动 */
@keyframes happy-dot-pulse { 0%,100%{ opacity:.82; } 50%{ opacity:1; } }
.eyes-z.happy .happy-dot   { animation: happy-dot-pulse 3.8s ease-in-out infinite; }
.eyes-z.happy .happy-dot.r { animation-delay: .28s; }
```

### 需要删除的旧代码
- `defs` 中的 `hL_${uid}` / `hR_${uid}` clipPath（底部曲线）
- `defs` 中的 `blush_${uid}` radialGradient（旧梯度腮红）
- 旧 `happyFace` 渲染分支中使用上述 defs 的整段代码

### prefers-reduced-motion 补充
```css
.eyes-z.happy .happy-pupil,
.eyes-z.happy .happy-dot { animation: none !important; }
```

## 2. 平静情绪 — 颜色修改

旧色 `#94a3b8`（压抑灰蓝）→ 新色 `#78b4a0`（哑光鼠尾草青绿，代表宁静而非低落）

### 需修改的位置

**CSS token：**
```css
/* 亮色模式 */
[data-emotion="平静"] { --emotion-color: #78b4a0; }
/* 暗色模式 */
[data-theme="dark"] [data-emotion="平静"] { --emotion-color: #8ecabc; }
```

**JS 颜色查表（EMOTION_HEX 或同等结构）：**
```js
light: { ..., '平静': '#78b4a0', ... }
dark:  { ..., '平静': '#8ecabc', ... }
```

## 3. 思考中三点律动 — 位置迁移

### 旧实现（需废弃）
HTML 元素 `<span class="think-dots"><i/><i/><i/></span>`，CSS 定位在 SVG 右侧：
```css
.think-dots {
  position: absolute;
  left: calc(100% + 12px); /* 右侧，会被容器遮挡 */
  top: 50%;
}
```

### 新实现
**三点移入 SVG 内部，置于两眼中上方（与困惑 `?` 号同区域）。**

在 Eyes 组件 SVG 内，thinking 状态下渲染：
```jsx
{thinking && !asleep && (
  <g className="z-think-dots">
    <circle cx="41" cy="-2" r="1.8" fill={fill}/>
    <circle cx="50" cy="-2" r="1.8" fill={fill}/>
    <circle cx="59" cy="-2" r="1.8" fill={fill}/>
  </g>
)}
```

坐标说明：viewBox 为 `0 0 100 44`，cx=41/50/59 水平居中于两眼之间，cy=-2 位于 viewBox 上边缘之上，**SVG 必须设置 `overflow: visible`**（或等效 style）才能显示负 y 坐标的内容。

### 新 CSS
```css
/* 旧 HTML think-dots 隐藏 */
.think-dots { display: none; }

/* 新 SVG think-dots */
.z-think-dots circle {
  transform-box: fill-box;
  transform-origin: center;
  animation: think-dot 1.4s ease-in-out infinite;
  opacity: .28;
}
.z-think-dots circle:nth-child(2) { animation-delay: .18s; }
.z-think-dots circle:nth-child(3) { animation-delay: .36s; }
```

`@keyframes think-dot` 保持不变：
```css
@keyframes think-dot {
  0%,100% { opacity: .22; transform: translateY(1px);  }
  42%     { opacity: .95; transform: translateY(-2px); }
}
```

### prefers-reduced-motion 补充
```css
.z-think-dots circle { animation: none !important; }
```
