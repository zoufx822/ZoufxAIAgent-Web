# v0.14 / v0.145 前端实现交接

本文档总结 Design demo（`Zoufx AI.html`）中已落地的所有视觉、交互、信息架构决策，供 Claude Code 在 Next.js 16 / React 19 / Tailwind 4 / @base-ui / shadcn / Zustand / streaming-markdown / Shiki / Motion / lucide-react 技术栈下复现。

请把 demo HTML 文件作为视觉真值参考（pixel-level reference）。本文档只描述**为什么这么做**和**契约**，不重复 CSS 数值——直接对照 demo 文件取值。

---

## 1. 总体定调

这一轮的核心目标：**让用户直观感受到 AI 在认识自己、在记得共同的事**。所有改动围绕"拟人化"，不允许出现"任务管理 / 后台管理"的语义。具体的克制点：

- 没有勾选 / 删除 / 编辑记忆的按钮（"AI 记得"，不是"用户的 TODO"）
- 没有进度百分比 / 解锁徽章 / 游戏化元素
- 不引入 Material UI / Ant Design
- 不显式展示 mood 的英文枚举值，所有可见标签必须是中文短词

## 3. PresenceSticky（顶部 banner）

### 3.1 数据来源

| 字段 | 来源 | 备注 |
|---|---|---|
| status | SSE `status` 事件 + 本地状态机 | 6 状态：idle / thinking / tooling / writing / error / asleep |
| mood   | SSE `mood` 事件                | 6 mood，详见 §7 |
| context | 前端派生                       | 见 §3.3 |
| spotlight | 前端派生                     | mood 变化触发，3 秒后回收 |

### 3.2 两态布局

| 态 | Eyes 尺寸 | 高度 | 内容顺序（居中） |
|---|---|---|---|
| collapsed | 32px | ~56px | `(eyes) · 情绪 · 状态(中文 + EN)` |
| spotlight | 88px | ~170px | flex column；表情上方，下方放大的「情绪 · 状态」 |

视觉：

- Eyes 颜色固定 `var(--accent)`（暖橙 `#d97757`），瞳孔 `var(--bg)`
- spotlight 态背景：`linear-gradient(180deg, var(--accent-s) 0%, var(--bg) 100%)`
- spotlight 触发动画：halo（径向渐变光晕）+ Eyes pop 弹缩 + 文字 rise

### 3.3 spotlight 触发规则

- mood 实际值变化（不是 lastMoodAt 刷新）触发
- 持续 3000ms 后自动回收
- 在已 spotlight 期间又触发，重置计时器
- 用户手动改 mood（调试时）也触发

### 3.4 collapsed 态的 mood 显示策略（沿用 v0.135 契约）

- 仅在 `STATUS_HAS_MOOD[status] === true` 时显示 mood 文字
- mood `lastMoodAt` 老于 5 分钟时降饱和（`stale`）
- 老于 15 分钟时不再显示

## 4. Eyes 表情系统（v0.14 rev6）

### 4.1 mood 词表（**简化到 6 个**）

```ts
type Mood = '平静' | '好奇' | '兴奋' | '困惑' | '难过' | '愤怒';
```

> ⚠️ 后端 `MoodPromptSection` 的可选词表请同步精简到这 6 个。其他情绪由前端默认 mood（按 intimacy 档位）兜底。

### 4.2 视觉机制（每个 mood 独占一个识别点）

| Mood | 独占机制 | 关键参数（与 demo 完全一致） |
|---|---|---|
| 平静 | 基准 | `pr:3.2, pdy:0, esy:1.0, blink:6s` |
| 好奇 | 瞳孔放大 + 上推 + 眨眼加快 | `pr:5.0, pdy:-3.2, blink:3.0s` |
| 兴奋 | 在好奇基础上加幅度 + 装饰符号 | `pr:5.4, pdy:-3.0, esy:1.08, blink:2.0s, sparkle:true` |
| 困惑 | 双瞳孔同向偏移（侧视）+ 眉心 `?` | `pdx:1.8, question:true` |
| 难过 | 下眼皮重抬 + 瞳孔下移（看着地面） | `pdy:1.8, esy:0.85, lidty:6.0` |
| 愤怒 | 上眼皮内侧斜压（怒眉）+ 小瞳孔 | `pr:2.2, liddy:5.0, lidty:2.0, lidSlant:8.0` |

### 4.3 Eyes 组件需支持的参数（命名与 demo 对齐）

- `pr / prR`：左/右瞳孔半径
- `pdx / pdy / pdxR`：瞳孔偏移
- `esy / esyR`：左/右眼椭圆 scaleY
- `liddy / liddyR / lidty / lidtyR`：上/下眼皮遮罩高度（左右独立）
- `lidSlant`：上眼皮内侧额外下压（polygon clip 实现"怒眉"）
- `sparkle`：兴奋 — 两侧外上角 4 角星 polygon + 辅点（CSS `sparkle-twinkle` 1.4s 闪烁）
- `question`：困惑 — 眉心 `?` symbol（CSS `question-bob` 2s 浮动）

### 4.4 context（用户活跃态，与 mood 正交）

- 前端派生，**不来自后端**
- 三档：`normal` / `long-silence`（>90s 无 mousemove/keydown）/ `high-intensity`（近 2 min ≥3 条消息）
- 监听 `mousemove` / `keydown` / `click` 刷新 `lastInputAt`
- 叠加效果：
  - `long-silence`：眨眼变慢 1.5× + 瞳孔下移 + esy 缩 + 上眼皮加压
  - `high-intensity`：眨眼快 0.6× + 瞳孔放大 1.08× + esy 上限拉到 1.15

### 4.5 默认 mood 兜底（按 intimacy）

```ts
const INTIMACY_DEFAULT_MOOD = {
  'stranger':    '好奇',
  'half-known':  '平静',
  'fully-known': '平静',
};
const effectiveMood = currentMood || INTIMACY_DEFAULT_MOOD[intimacy];
```

## 6. Intimacy 三档（v0.14 关系阶段）

### 6.1 派生

```ts
function intimacyMode(hot) {
  const filled = HOT_MEMORY_ALL.filter(f => hot[f.key]?.trim()).length;
  const r = filled / 10;
  if (r < 0.3) return 'stranger';     // <3 字段
  if (r < 0.7) return 'half-known';   // 3-6 字段
  return 'fully-known';                // ≥7 字段
}
```

阈值需与后端 `fill_ratio` 保持一致（v0.14 文档定义）。

### 6.2 UI 表达

| 档位 | Home 副文案 | Hot Memory 计数 | Home chips |
|---|---|---|---|
| stranger    | "我们才刚认识。先随便聊聊？" | 显示 `N/10` | "你想聊点什么？" / "你怎么称呼自己" / "介绍一下你自己" |
| half-known  | "继续聊吧——我还在慢慢认识你。" | 不显示 | 任务型 chips |
| fully-known | 走时间 greeting，不特殊化 | 不显示 | 全量 chips |

> ⚠️ 用户印象的 `N/10` 计数**只在 stranger 档显示**，其他档位用户已经懂了，不需要计数器。

## 7. Memory Anchors（v0.145 · 三层衰减摘要）⭐ 新增

### 7.1 数据契约

```ts
type MemoryAnchors = {
  near: AnchorSummary[];   // ~200 字 / 条，full body
  mid:  AnchorSummary[];   // ~50 字 / 条，title + 短描述
  far:  { count: number; summary: string }; // 一行汇总
} | null;

type AnchorSummary = {
  id: string;
  title: string;
  body?: string;       // near 必有，mid 可选
  timeLabel: string;   // "昨天" / "2 天前" / "上周" / "两周前" / "2024 年"
  mood?: Mood | null;  // 可选，若历史 mood 有记录
};
```

### 7.2 视觉契约

| 层级 | 默认状态 | 内容 |
|---|---|---|
| 近记忆 · recent | 默认显示前 2 条；"展开剩余 N 条" 按钮可展开/收起 | 卡片 + title (13px 500) + body (12px `--t2`) + meta (9.5px mono `--t3`) + mood 圆点（accent 色） |
| 中记忆 · earlier | 默认折叠（只看到 tier 标题行）；chevron 点击展开 | 紧凑单行 `[标题 ─ mood点 ─ 时间]`，1 行省略号 |
| 远记忆 · distant | 永久折叠（无展开） | dashed 边的一行 `"N 个更早的对话 · 概要"` |

### 7.3 空态

```
记忆锚点
　　这是我们的第一次对话。
```

### 7.4 关键克制点

- ❌ 不展示原始消息内容；本 section 展示的是**跨锚点压缩摘要**（来自 `AnchorContextSection`）
- ❌ 不展示日期时间戳；只有人类可读的相对时间标签（"昨天" / "上周" / "2024 年"）
- ❌ mood 不用文字标签，只用 accent 色小圆点 + `title` 悬停提示
- ✅ 整个 section 折叠层级（半折叠 mid + 全折叠 far）必须保留；这是密度控制的关键

## 9. Commitments（承诺）

### 9.1 数据契约

`GET /ai/memory/cold/{userId}?type=commitment` → `Map<UUID, description>`，value 必须带前缀（LLM 写入约束）：

```
"我（AI）答应{对方称呼}：..."     → AI 单方承诺
"{对方称呼}答应我：..."            → 用户单方承诺
"我们约定：..."                    → 双向约定
```

### 9.2 前端 parser

```ts
function parseCommitment(text: string): { dir: 'ai'|'user'|'mutual'; who?: string; body: string }
```

实现：见 demo 文件，正则匹配三种前缀。

### 9.3 视觉契约

| dir | 箭头 | 颜色（light / dark）| meta 文字 |
|---|---|---|---|
| ai     | → | `#0891b2` / `#22d3ee` | "我承诺" |
| user   | ← | `#d97706` / `#fbbf24` | "{who}承诺" |
| mutual | ↔ | `var(--t1)`           | "双方约定" |

每条：左侧大字号箭头 + 右侧 meta 小字（mono uppercase）+ body 正文。

右栏只显示前 3 条；"全部"通过「回顾全部 →」入口进 LookBackModal。

### 9.4 关键克制点

- ❌ 无勾选框、无 done 状态、无删除按钮
- ❌ 不识别"周一 09:00"这种时间字符串做提醒
- 承诺存在的语义是"AI 记得"，**不是用户的 TODO**
